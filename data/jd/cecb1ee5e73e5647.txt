Your impact
Role
As an AI Cybersecurity Engineer Intern, you will collaborate with experienced security researchers and data scientists to develop automated threat detection
models, analyze adversarial AI risks, and enhance enterprise security tooling. In this role, you will:
- Build and refine machine learning pipelines using Python and modern data frameworks to automate the classification of high-volume telemetry, suspicious
network behavior, and vulnerability signals.
- Investigate emerging AI-specific security risks—such as prompt injection, data poisoning, and model evasion techniques—to help design proactive defensive
safeguards across our cloud platforms.
- Evaluate detection metrics and model performance alongside engineering mentors to improve classification accuracy, reduce false positive alerts, and
accelerate security response workflows.
- Deliver an impactful capstone project applying machine learning algorithms to real-world cybersecurity telemetry to showcase your innovations to Security &
Trust Organization (STO) leadership.
Minimum Qualifications
- Currently enrolled in an undergraduate degree program (Associate's or Bachelor's).
- Qualifying education should be in Cybersecurity, Computer Science, Computer Engineering, Artificial Intelligence, Data Science, Information Technology, or a
related field.
- Expected to continue enrollment in degree program following completion of the internship.
- Foundational academic coursework or project experience in Python programming for data analysis, scripting, or algorithm development.
Preferred Qualifications
- Academic coursework, laboratory experiments, or student research in machine learning frameworks (such as PyTorch, TensorFlow, Scikit-learn, or Pandas).
- Foundational knowledge of core cybersecurity concepts, such as network protocols, vulnerability management, threat intelligence, or MITRE ATT&CK frameworks.
- Hands-on exposure to cloud environments (such as Amazon Web Services, Microsoft Azure, or Google Cloud Platform) or containerization tools like Docker.
- Participation in collegiate cybersecurity competitions (CTFs), Kaggle data challenges, open-source AI projects, or campus security clubs.
- Strong analytical curiosity, collaborative communication skills, and an enthusiasm for exploring the intersection of artificial intelligence and defensive
security operations.
