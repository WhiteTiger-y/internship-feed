Role Summary
Software-defined vehicles generate enormous amounts of data, from vehicle telemetry to manufacturing and fleet operations. As a Data Engineering intern, you
will help turn that data into usable, reliable infrastructure and analytics, working on data pipelines, machine learning platforms, or the software and
analytics supporting fleet and manufacturing applications.
Specific Project Areas Vary By Team And May Include
- Developing SQL and Python based data transformation and pipeline code
- Building and maintaining ELT pipelines and analytics workflows on Databricks or similar platforms
- Supporting machine learning model development, evaluation, or deployment infrastructure
- Contributing to software for fleet management or manufacturing execution applications that depend on reliable data
- Building automated data quality tests and integrating with CI/CD workflows
Responsibilities
- Design, build, or maintain data pipelines, analytics workflows, or ML supporting infrastructure
- Write Python and SQL code to process, transform, and validate data
- Collaborate with data scientists, analysts, or software engineers to meet data or platform needs
- Contribute to automated testing for data quality and pipeline reliability
- Document your work and share progress with your team throughout the internship
Qualifications
Minimum:
- Currently enrolled in a Bachelor's or Master's program at an accredited US university
- Proficient in Python and SQL
Preferred
- Actively pursuing a degree in Computer Science, Mathematics, Data Science, or a closely related field, with intent to return to school after the internship
- Coursework or project experience with data engineering, analytics, or machine learning
- Familiarity with cloud data platforms such as Databricks, Snowflake, or Google BigQuery
- Exposure to data transformation tools such as dbt, or infrastructure as code tools such as Terraform
- Interest in applying data skills to vehicle, fleet, or manufacturing use cases
