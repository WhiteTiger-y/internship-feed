Job Summary
We are currently seeking a Data Scientist and AI Developer Intern from June 2027 – May 2028. This position works for approximately 37.5 hours per week in the
summer and 20 hours per week for the remainder of the internship.
The intern will be accountable for ideating, designing, developing, and supporting applications and solutions to explore various machine intelligence techniques
including but not limited to natural language processing (NLP), predictive analysis using supervised and unsupervised machine learning (ML), and generative AI
(GenAI) using large language models (LLM) for use cases that focus on data quality and data governance. The role may also involve working with cloud
technologies and services such as AWS and GCP to support scalable data processing, AI/ML experimentation, application deployment, and integration with
enterprise data platforms. The position requires familiarity with AI/ML/NLP/GenAI techniques, SQL databases and data manipulation, API architectures, cloud-
based services, and user interface development. Strong work ethic and eagerness and ability to self-learn is critical.
Responsibilities
- Design, develop, and support AI/ML/NLP/GenAI solutions.
- Analyze data using SQL and other techniques.
- Extract data using REST APIs.
- Develop and support simple user interfaces.
- Support development, deployment, and integration of cloud-based data and AI solutions using technologies such as AWS and GCP.
- Create simple visualization.
- Assist in various other related functions such as preparing documentation, taking meeting notes, plan and manage work, make presentations, etc.
- Augment knowledge with self-driven learning.
Qualifications
Qualified candidates must be a current graduate school student pursuing computer science, data analytics or a related discipline. Experience with SQL
development, data analysis using MS Excel, developing simple web portals and machine learning (NLP, predictive analytics) is required. Prior academic or
professional work experience is preferred; experience in the pharmaceutical industry and/or with clinical data is a plus. Enthusiasm, eagerness to learn and
take on responsibilities, and teamwork are essential qualities.
