Our Information Security team within Corporate IT is looking for an intern to support AI-enabled security engineering initiatives. This position provides the
opportunity to gain hands-on experience applying artificial intelligence, automation, software development, and security engineering practices while completing
your education.
Duties & Responsibilities
- Assist with developing, testing, and documenting AI-enabled security tools, workflows, and prototypes
- Use scripting and APIs to automate security engineering tasks, data collection, enrichment, analysis, and reporting
- Support the integration and evaluation of security technologies across cloud, identity, endpoint, network, and data environments
- Analyze security data to identify patterns, anomalies, potential threats, and opportunities to improve controls
- Help assess the security of AI solutions, including access controls, data protection, prompt and model risks, and responsible-use safeguards
- Build and maintain technical documentation, test plans, code repositories, and repeatable engineering procedures
- Collaborate with security engineers and internal stakeholders to define requirements, troubleshoot issues, demonstrate solutions, and deliver project outcomes
Required Skills & Experience
- Education: Currently enrolled in a degree program in Cybersecurity, Computer Science, Software Engineering, Data Science, Artificial Intelligence, or a
related technical field
- Foundational knowledge of cybersecurity concepts such as identity and access management, cloud security, endpoint security, networking, secure software
development, or threat detection
- Intermediate programming or scripting language skill, such as Python, PowerShell, JavaScript, or C#
- Understanding of AI and machine learning concepts, large language models, or data analysis
- Ability to troubleshoot technical problems, learn unfamiliar technologies, and take ownership through resolution
- Ability to work independently and collaborate effectively while sharing knowledge as part of a team
- Ability to manage time, prioritize tasks, and communicate technical information clearly in writing and conversation
Preferred Skills & Experience
- Academic, personal, or work projects involving generative AI, machine learning, security automation, or data engineering
- Experience using APIs, Git-based development workflows, notebooks, or development environments
- Knowledge of security capabilities within Microsoft Azure or Microsoft 365, including identity, endpoint, cloud, or security monitoring technologies
- Exposure to cloud platforms, containers, Linux, infrastructure as code, CI/CD pipelines, or policy as code
- Understanding of secure coding, threat modeling, vulnerability management, or common security frameworks
- Experience working with structured or unstructured security data and creating useful analyses or visualizations
