Position Profile
Ricoh is seeking a highly motivated summer intern to help build an AI-powered globalization platform that translates our product documentation and software into
eleven languages. Our translation process has already moved from fully manual to hybrid automation, and the next step is to bring translation fully in-house: an
automated, AI-driven pipeline that reduces turnaround from weeks to a single day while raising translation quality and consistency.
The intern will join this project during its validation and pilot phases, working on the machine learning and engineering problems that determine whether an
automated translation can be trusted enough to ship to customers. This is applied work on a system with real users, measurable cost impact, and a clear path to
production.
Examples Of Summer Projects
- Build and run evaluation methods that measure machine translation quality across multiple languages, and help define what “good enough to ship” means for
customer-facing content.
- Develop a terminology checker that enforces Ricoh product terminology and brand language consistently across every supported language.
- Implement delta translation—detecting and translating only changed content—to cut token cost and processing time on document updates.
- Work with large language models to improve translation accuracy on structured technical content, including XML-based documentation, tagging, and formatting
preservation.
- Help automate the end-to-end pipeline that receives translation packages from development teams, processes them, and checks completed translations back into
source control.
- Analyze and refine AI outputs to improve accuracy and usability, and present findings to cross-functional development, documentation, and localization teams.
Job Duties And Responsibilities
- Contribute working code to an active engineering project alongside full-time engineers.
- Design and execute experiments to evaluate model and pipeline performance, and document the results.
- Collaborate with cross-functional teams across documentation, software development, and infrastructure.
- Present progress and final results to technical stakeholders and department leadership.
