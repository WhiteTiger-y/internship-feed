What you’ll be doing:
- Build and deliver a scoped software tool or automation feature using AI-assisted development tools, with guidance from your technical mentor.
- Work with partners across sales, marketing, strategy and operations, program management, and solutions architecture to understand manual workflows and define
project requirements.
- Test, debug, and refine your work, following the team’s practices for code review, data handling, and deployment.
- Analyze usage and user feedback to understand adoption, identify improvements, and help scope future projects.
- Create documentation and quick-start guides that help colleagues adopt and use the tools you build.
What we need to see:
- Pursuing a BS or MS in Computer Science, Software Engineering, Data Science, or an equivalent program area.
- Programming experience in Python, JavaScript, or TypeScript through coursework, personal projects, or previous internships.
- Experience building a software application, automation script, or data project, with the ability to explain your approach and technical decisions.
- Familiarity with APIs, structured data, and Git or another version-control system.
- Experience testing and debugging code, including checking the correctness of AI-generated outputs.
Ways to stand out from the crowd:
- Projects using AI coding assistants, large language models, or workflow automation.
