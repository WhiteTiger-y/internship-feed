What's the role?
HERE utilizes many disparate and complementary data sources that, only together, can provide the full context needed for HERE's map making. The varied nature of
the sources requires intelligent, data-driven methods for data fusion involving state-of-the-art approaches in machine learning, artificial intelligence and
robotics engineering. Interns will provide research, investigation, testing and evaluation of data fusion approaches to elevate the accuracy and coverage of the
data observations used to build HERE's maps, producing code in Python and/or C++.
- Interns will work alongside a HERE mentor to address emerging needs for HERE's products
- Production-level code that meets code review standards
- Documentation for software functionality
- Presentation of results to key stakeholders
