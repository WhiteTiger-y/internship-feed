Join NVIDIA’s Physical AI Technical Marketing team to help developers learn how to build AI systems that perceive and interact with the physical world. Work
with engineers and educators to turn robotics and simulation workflows into tested labs, tutorials, and learning experiences. You’ll own a scoped project from a
working example through learner testing and publication, helping developers and partners put NVIDIA technology into practice.
What you’ll be doing:
- Collaborate with technical marketing, product, engineering, and training teams to design learning content for a selected robotics, simulation, or AI workflow
accurately
- Build developer-friendly hands-on learning content with clear prerequisites, exercises, expected results, and troubleshooting guidance.
- Test tutorials and lab environments from a new learner’s perspective; reproduce failures and work with engineers to resolve them.
- Create reusable diagrams, short demonstrations, and knowledge checks that connect technical concepts to practical tasks.
- Maintain learning materials in version control, incorporate learner feedback, and document updates so the content stays usable as software changes.
What we need to see:
- Pursuing a BS or MS in Computer Science, Robotics, Electrical Engineering, Computer Engineering, or equivalent program area.
- Python programming demonstrated through coursework, a research project, or a software project.
- Coursework or project experience in at least one of robotics, machine learning, computer graphics, or simulation.
- Experience using Git and a Linux development environment to run, debug, and document software.
- A technical writing or teaching sample, such as a tutorial, project README, lab guide, or recorded demonstration that explains a working project.
- Demonstrated experience leveraging open models and agentic tools to produce production-ready content and materials.
Ways to stand out from the crowd:
- A project using one or more of NVIDIA Isaac Sim, Isaac Lab, Cosmos, Jetson, Omniverse libraries, OpenUSD, or ROS (Robot Operating System).
- Experience turning a robotics, synthetic-data, or simulation project into a reproducible example others can run.
- Teaching, tutoring, workshop, or open-source contribution experience, with examples of improvements made from user feedback.
- Passion for creating technical diagrams, videos, or accessible learning materials.
- Using AI tools with a documented process for checking their output.
