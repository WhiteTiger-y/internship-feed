Job Description
Intern – AI-Agentic Embedded Software Development - Bothell, WA - Summer 2027
Are you interested in an Intern opportunity with Philips? We welcome individuals who are currently pursuing an undergraduate (BS) and/or graduate (MS) degree to
apply to our intern opportunities at our sites across the US. Through these roles you will gain meaningful, hands-on experience in engineering for a HealthTech

Your role
The intern will support the development and implementation of AI-enabled workflows and agents across the software development lifecycle. Responsibilities may
include leveraging AI agents to assist with requirements analysis, software architecture and design, embedded software development, automated testing,
debugging, technical documentation, continuous integration and continuous delivery (CI/CD), and software deployment.
Job Responsibilities
- Use AI agents (e.g., GitHub Copilot and similar tools) to analyze product requirements, identify gaps, and draft clear, testable software requirements.
- Contribute to CI/CD pipelines (e.g., GitHub Actions) for automated builds, static analysis, testing, and deployment.
- Support software architecture and design activities, including multithreaded, event-driven designs for real-time embedded systems.
- Evaluate AI agent workflows across the software development lifecycle (SDLC), measure productivity and quality impact, and share findings and best practices
with the team.
- Design automation solutions to verify complex embedded system features, improving test coverage and accuracy in both manual and automated testing.
- Develop and maintain software applications, libraries, and frameworks in C/C++ or Python to automate test development, test execution, and error extraction
for embedded products.
- Enhance and optimize the build pipeline and build infrastructure using GitHub and Windows-based tools to improve development efficiency and speed.
- Innovatively develop techniques to automate manual tasks within the software development lifecycle, reducing bottlenecks and improving overall process
efficiency.
You are the right fit if
- Currently pursuing a Bachelor’s or Master’s degree in Computer Engineering, Electrical Engineering, Computer Science, Software Engineering, or a related field
- Familiarity with Python for scripting and CI/CD automation
- Experience building AI agent skills and custom agent profiles
- Prior course or project work and interests in embedded software development or software development
- Proficiency in Python and C/C++, with an interest in developing applications and libraries to automate processes
- Hands-on experience with Windows and/or Linux environments.
- Familiarity with GitHub and GitHub Actions (or similar CI/CD tools) for version control, automated builds, and deployments is a plus
- You must be able to successfully perform the following minimum Physical, Cognitive and Environmental job requirements with or without accommodation for this
position.
