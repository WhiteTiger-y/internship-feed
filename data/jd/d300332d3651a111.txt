The Opportunity
The AI Full Stack Developer Consulting Intern will focus on building and reviewing software in an AI-enabled development environment. This role is designed for
a strong programmer who can assess code written or assisted by AI, identify issues, improve quality, and work within modern software delivery practices
including source control, CI/CD, GitOps, and DevOps. The right candidate will be comfortable both creating code and challenging whether generated code is
secure, maintainable, testable, and fit for purpose.
Key Responsibilities:
- Develop, review, test, debug, and improve code used in Elire AI prototypes, tools, integrations, and internal solutions.
- Review AI-generated or AI-assisted code for correctness, maintainability, performance, security, and alignment with development standards.
- Build or support scripts, services, APIs, automations, and proof-of-value applications using appropriate programming languages and frameworks.
- Work with Git-based source control, branching, pull requests, code review, and version-management practices.
- Support CI/CD workflows and help automate build, test, deployment, and validation processes.
- Apply GitOps and DevOps concepts to improve repeatability, traceability, and reliability of software delivery.
- Troubleshoot technical issues, evaluate alternative solutions, and explain the reasoning behind implementation decisions.
- Document code, workflows, testing results, and technical recommendations; collaborate with Elire AI and technical leaders and present a final project.
Required Qualifications:
- Currently pursuing an Undergraduate, Master's or PhD in Computer Science, Information Technology, Cybersecurity, Network Engineering, Cloud Computing,
Engineering, or a closely related technical field.
- Strong understanding of networking fundamentals including IP addressing, subnets, routing, DNS, connectivity, and network security concepts.
- Hands-on knowledge of virtual cloud networking / VCN concepts and cloud infrastructure.
- Experience with Kubernetes (K8s), RKE2, or comparable container-orchestration technologies.
- Understanding of cluster deployment, scaling, availability, and troubleshooting concepts.
- Strong critical thinking and problem-solving skills; able to diagnose technical issues and make reasoned infrastructure recommendations.
- Ability to document architectures, configurations, issues, and technical decisions clearly and professionally.
Preferred Qualifications
- Hands-on exposure to CI/CD platforms, GitOps workflows, DevOps tooling, or infrastructure-as-code practices.
- Experience with containers, Docker, Kubernetes, or cloud-native application development.
- Exposure to generative AI APIs, coding copilots, LLM-based development workflows, or agentic development tools.
- Exposure to cloud platforms such as Oracle Cloud, AWS, Azure, or GCP.
- Prior research, internship, open-source, or project experience building production-oriented software or AI-enabled applications.
What You’ll Gain:
- Real-world experience applying AI and advanced technology in a consulting and enterprise environment.
- Hands-on work with experienced consultants, technical leaders, and Elire innovation initiatives.
- Professional development focused on critical thinking, communication, problem-solving, and client-ready delivery.
- The opportunity to own meaningful work and present findings or a final project at the end of the internship.
- Potential consideration for an internship extension based on business need and performance; an extension may be remote.
